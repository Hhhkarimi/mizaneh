# میزانه — رابط تازه، برنامهٔ کامل

این نسخه خود برنامهٔ واقعی است. همهٔ ورودی‌های چهار مرحله، ورودی‌های اختصاصی سه هدف، بررسی شرایط سلامت، محاسبات، جدول هفتگی، جزئیات وعده‌ها، ویرایش، غذای/دستور سفارشی، فهرست خرید، ذخیره، نسخه‌بندی، پیگیری و دریافت متن، همان پیاده‌سازی اصلی هستند.

تغییرها: فرم عریض‌تر، معرفی کوچک‌تر، مراحل دارای نام، متن خواناتر، دسترسی مستقیم به بخش‌های نتیجه، انتخاب روز در موبایل، شبکهٔ خوانا برای تمام مواد مغذی هر وعده و قرارگیری درست اعلان بازیابی زیر نوار ثابت.

## اجرای Next.js

Node.js 22.22 یا جدیدتر:

```sh
npm ci
npm run dev
```

`app/ui-refinement.css` پس از CSS اصلی بارگذاری می‌شود. منطق `lib/`، `hooks/`، مؤلفه‌های فرم، ویرایش و پیگیری تغییر نکرده است.

## فایل مستقل

`mizaneh.html` همان `app/DietPlanner.tsx` را با React اجرا می‌کند و تمام فونت و کد را داخل فایل دارد. ذخیرهٔ محلی و کپی به قابلیت مرورگر برای مبدأ file:// وابسته است؛ اجرای فایل تحت localhost نیز ممکن است. نسخهٔ مستقل Service Worker و فرادادهٔ سمت سرور Next.js را اجرا نمی‌کند.

بازسازی فایل مستقل در محیط معمولی:

```sh
npm install --no-save esbuild@0.25.12
npm run build:offline
```

خروجی: `build/mizaneh.html`. esbuild فقط برای ساخت نسخهٔ مستقل لازم است. در محیط فعلی، باندل با CLI رسمی ساخته و با `node scripts/build-offline.mjs --assemble-only` یکپارچه شد.

گزارش دقیق بررسی و محدودیت‌های محیط در `UI-VERIFICATION.md` است. این تغییرها لایهٔ نمایش و ابزار ساخت فایل مستقل را شامل می‌شوند.
