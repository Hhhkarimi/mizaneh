# میزانه

میزانه یک برنامه‌ریز غذایی علمی، فارسی و RTL برای بزرگسالان است. محصول فعلی کاهش وزن حفظ شده و دو هدف مستقل «افزایش حجم عضله» و «افزایش وزن» به آن افزوده شده‌اند. برای وضعیت‌های سلامت پایدار یا تحت‌پیگیری نیز برنامهٔ حمایتیِ شرط‌محور می‌سازد؛ وضعیت‌های اورژانسی یا ناپایدار همچنان نیازمند رسیدگی فوری‌اند.

## امکانات اصلی

- انتخاب مستقیم یکی از سه هدف از همان ابتدای ورود: کاهش وزن، افزایش حجم عضله یا افزایش وزن سالم
- سیاست محاسباتی جدا و نسخه‌دار برای کاهش وزن، حجم عضله و افزایش وزن سالم
- نمایش عدم‌قطعیت برآورد انرژی و بازبینی تدریجی براساس روند وزن
- غربالگری غیرتشخیصی سن، بارداری/شیردهی، اختلال خوردن، کاهش وزن ناخواسته، خطر بازغذیه، بیماری‌های نیازمند تغذیه‌درمانی، فشار خون، قند خون و چربی خون
- تولید برنامهٔ حمایتی برای شرایط پایدار، با ورودی‌های اختصاصی مانند سه‌ماههٔ بارداری، IDDSI، مرحلهٔ کلیه/کبد، آزمایش‌ها، مرحلهٔ رژیم جراحی و محدودیت‌های ثبت‌شده توسط تیم درمان
- توقف برنامهٔ عادی فقط برای علائم حاد و ناپایدار که ادامه می‌تواند رسیدگی فوری را به تأخیر بیندازد
- برنامهٔ هفتگی، چهار چیدمان، جایگزین‌های توضیح‌دار و فهرست خرید
- ویرایش مقدار، نام، زمان، ترتیب و نوع وعده؛ افزودن/حذف/کپی، قفل روز و وعده، واگرد/ازنو و بازنشانی
- غذای سفارشی با مقدار و واحد سهم، دادهٔ تغذیه‌ای و یادداشت منبع
- دستور غذای سفارشی با مواد، مقدار، واحد، حالت خام/پخته، بازده کل، تعداد سهم و محاسبهٔ هر سهم
- محاسبهٔ مجدد انرژی، پروتئین، کربوهیدرات، چربی، فیبر، چربی اشباع، سدیم، قند افزوده، پتاسیم، کلسیم، آهن، منیزیم، فسفر، روی، فولات، ید، B12، ویتامین D، کولین و وضعیت سازگاری پس از هر ویرایش
- ذخیرهٔ اختیاری چند برنامه روی همان دستگاه، نسخه‌بندی، مقایسه و مهاجرت نشست قدیمی
- ثبت روند وزن، دور کمر، پایبندی، اشتها، انرژی، خواب و تحمل گوارشی؛ برای حجم عضله عملکرد و ریکاوری نیز ثبت می‌شود
- پیشنهاد تنظیم انرژی حداکثر ۱۰۰ کیلوکالری، فقط پس از روند کافی و با پذیرش صریح کاربر
- بدون حساب، backend، analytics، تبلیغات یا انتقال خودکار دادهٔ سلامت
- Vazirmatn به‌عنوان تنها فونت و attribution قابل‌مشاهدهٔ سازنده

## مرز پزشکی

وجود بیماری به‌تنهایی مانع تولید برنامه نیست. میزانه برای وضعیت‌های پایدار، بر اساس اطلاعات واردشده و محدودیت‌های ثبت‌شده، برنامهٔ حمایتی و هشدار برجستهٔ هماهنگی با پزشک/متخصص تغذیه ایجاد می‌کند. با این حال ابزار تشخیص یا درمان خودکار نیست، دارو یا دوز انسولین را تغییر نمی‌دهد، مکمل بارداری تجویز نمی‌کند، سطح IDDSI یا محدودیت کلیوی را حدس نمی‌زند و جایگزین تغذیه‌درمانی پزشکی نیست. علائم حاد و ناپایدار مسیر برنامهٔ عادی را متوقف می‌کنند.

جزئیات سیاست و منابع در `docs/clinical-nutrition-v5.md` و `docs/evidence-registry-v5.csv` قرار دارد.

## اجرای محلی

نیازمندی: Node.js نسخهٔ `22.22.0` یا جدیدتر.

```bash
npm ci
npm run dev
```

سپس `http://localhost:3000` را باز کنید.

## بررسی انتشار

```bash
npm run lint
npm run test
npm run build
npm audit --omit=dev
```

وضعیت دقیق بررسی همین پیاده‌سازی در `docs/phase-4/verification-report.md` ثبت شده است.

## ساختار مهم

```text
components/
  goal-selection/      انتخاب مستقیم سه هدف
  safety-screen/       غربالگری ایمنی و ورودی‌های بالینی شرط‌محور
  meal-editor/         ویرایش پیشرفته و غذای/دستور سفارشی
  progress/            روند و پیشنهاد تنظیم
lib/
  calculations/        EER و سیاست‌های نسخه‌دار هر هدف
  clinical/            پروفایل تغذیهٔ حمایتی و رجیستری منابع
  safety/              تفکیک وضعیت پایدار از علائم حاد و ارجاع
  plan/                تولید، جایگزینی، ویرایش و محاسبهٔ مجدد
  progress/            روند مقاوم و پیشنهادهای قابل رد/تغییر
  storage/             مهاجرت v1 و فضای کاری چندبرنامه‌ای v2
  types.ts             مدل دامنهٔ مشترک
```

اسناد پژوهش، evidence matrix، specification تصویب‌شده و گزارش نهایی در `docs/phase-1` تا `docs/phase-4` قرار دارند.

## سخت‌گیری انتشار و نگه‌داری داده

برای اجرای یکپارچهٔ lint، تست، کنترل معماری، تاریخ بازبینی سیاست‌های فعال و build:

```bash
npm run verify
```

داده‌های سلامت فقط پس از ذخیرهٔ صریح کاربر در مرورگر نگه‌داری می‌شوند و پس از ۱۸۰ روز بدون ذخیرهٔ مجدد، هنگام خواندن به‌صورت خودکار حذف می‌شوند.
