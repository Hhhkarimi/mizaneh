# میزانه

میزانه یک برنامه‌ریز غذایی علمی، فارسی و RTL برای بزرگسالانی است که در محدودهٔ برنامه‌ریزی عمومی تغذیه قرار می‌گیرند. محصول فعلی کاهش وزن حفظ شده و دو هدف مستقل «افزایش حجم عضله» و «افزایش وزن» به آن افزوده شده‌اند.

## امکانات اصلی

- انتخاب هدایت‌شدهٔ هدف، مقایسهٔ اختیاری سه هدف و انتخاب مستقیم برای کاربران بازگشتی
- سیاست محاسباتی جدا و نسخه‌دار برای کاهش وزن، حجم عضله و افزایش وزن سالم
- نمایش عدم‌قطعیت برآورد انرژی و بازبینی تدریجی براساس روند وزن
- غربالگری غیرتشخیصی سن، بارداری/شیردهی، اختلال خوردن، کاهش وزن ناخواسته، خطر بازغذیه، بیماری‌های نیازمند تغذیه‌درمانی، فشار خون، قند خون و چربی خون
- جلوگیری از تولید برنامهٔ عادی برای وضعیت‌های خارج از محدودهٔ ایمن؛ بدون امکان عبور با disclaimer
- برنامهٔ هفتگی، چهار چیدمان، جایگزین‌های توضیح‌دار و فهرست خرید
- ویرایش مقدار، نام، زمان، ترتیب و نوع وعده؛ افزودن/حذف/کپی، قفل روز و وعده، واگرد/ازنو و بازنشانی
- غذای سفارشی با مقدار و واحد سهم، دادهٔ تغذیه‌ای و یادداشت منبع
- دستور غذای سفارشی با مواد، مقدار، واحد، حالت خام/پخته، بازده کل، تعداد سهم و محاسبهٔ هر سهم
- محاسبهٔ مجدد انرژی، پروتئین، کربوهیدرات، چربی، فیبر و وضعیت سازگاری پس از هر ویرایش
- ذخیرهٔ اختیاری چند برنامه روی همان دستگاه، نسخه‌بندی، مقایسه و مهاجرت نشست قدیمی
- ثبت روند وزن، دور کمر، پایبندی، اشتها، انرژی، خواب و تحمل گوارشی؛ برای حجم عضله عملکرد و ریکاوری نیز ثبت می‌شود
- پیشنهاد تنظیم انرژی حداکثر ۱۰۰ کیلوکالری، فقط پس از روند کافی و با پذیرش صریح کاربر
- بدون حساب، backend، analytics، تبلیغات یا انتقال خودکار دادهٔ سلامت
- Vazirmatn به‌عنوان تنها فونت و attribution قابل‌مشاهدهٔ سازنده

## مرز پزشکی

میزانه ابزار تشخیص یا درمان نیست، دارو را تغییر نمی‌دهد و برای فشار، قند یا چربی خون هدف درمانی نمی‌سازد. کاربران خارج از محدودهٔ برنامه‌ریزی عمومی باید به متخصص مناسب ارجاع داده شوند.

## اجرای محلی

نیازمندی: Node.js نسخهٔ `22.22.0` یا جدیدتر.

```bash
npm ci
npm run dev
```

سپس `http://localhost:3000` را باز کنید.

## بررسی انتشار

```bash
npm run lint
npm run test
npm run build
npm audit --omit=dev
```

وضعیت دقیق بررسی همین پیاده‌سازی در `docs/phase-4/verification-report.md` ثبت شده است.

## ساختار مهم

```text
components/
  goal-selection/      انتخاب هدایت‌شده و مقایسهٔ اهداف
  safety-screen/       غربالگری ایمنی و دادهٔ قلبی‌ـ‌متابولیک
  meal-editor/         ویرایش پیشرفته و غذای/دستور سفارشی
  progress/            روند و پیشنهاد تنظیم
lib/
  calculations/        EER و سیاست‌های نسخه‌دار هر هدف
  safety/              تعیین محدودهٔ ایمنی و ارجاع
  plan/                تولید، جایگزینی، ویرایش و محاسبهٔ مجدد
  progress/            روند مقاوم و پیشنهادهای قابل رد/تغییر
  storage/             مهاجرت v1 و فضای کاری چندبرنامه‌ای v2
  types.ts             مدل دامنهٔ مشترک
```

اسناد پژوهش، evidence matrix، specification تصویب‌شده و گزارش نهایی در `docs/phase-1` تا `docs/phase-4` قرار دارند.
