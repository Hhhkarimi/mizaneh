# میزانه

برنامه‌ریز غذایی علمی و هفتگی برای بزرگسالان سالم؛ با محاسبه انرژی روزانه،
درشت‌مغذی‌ها، فیبر، جدول هفت‌روزه، جایگزین‌های هم‌گروه، فهرست خرید و نقشه
آماده‌سازی وعده‌ها.

## امکانات

- محاسبه سوخت‌وساز پایه با معادله میفلین–سن ژئور
- برآورد نیاز نگهدارنده با توجه به سطح فعالیت
- تعیین هدف روزانه با سقف کسری محافظه‌کارانه
- ساخت جدول غذایی کامل از شنبه تا جمعه
- چهار چیدمان متنوع، سریع، آماده‌سازی جمعی و پروتئین‌محور
- پشتیبانی از سبک متعادل، گیاه‌خواری، مدیترانه‌ای و پروتئین بیشتر
- فیلتر حساسیت‌ها و غذاهای ناپسند
- جزئیات سهم، انرژی، پروتئین، فیبر و زمان آماده‌سازی هر وعده
- جایگزین‌های هم‌گروه و فهرست خرید دسته‌بندی‌شده (به همراه یادداشت روشن که فهرست، گروه‌بندی‌شده است نه مقدار دقیق خرید)
- جایگزینی هر وعده با گزینه‌ای هم‌گروه، بدون به‌هم‌خوردن هدف کالری همان وعده
- یک یادداشت ایمنی/حریم‌خصوصی یک‌باره پیش از شروع محاسبه (این ابزار جایگزین توصیه پزشکی نیست)
- دریافت نسخه متنی و نمای مناسب چاپ
- طراحی راست‌چین، واکنش‌گرا و دسترس‌پذیر
- متادیتای کامل، داده ساختاریافته، نقشه سایت و فایل راهنمای خزنده‌ها
- سربرگ‌های امنیتی و عدم ذخیره داده‌های فرم

## اجرای محلی

نیازمندی: Node.js نسخه ۲۲ یا جدیدتر.

```bash
npm ci
npm run dev
```

سپس نشانی `http://localhost:3000` را باز کنید.

## استقرار در Vercel

1. محتویات این پوشه را در یک مخزن GitHub قرار دهید.
2. در Vercel گزینه **Add New Project** را انتخاب و مخزن را وارد کنید.
3. چارچوب پروژه به‌صورت خودکار **Next.js** تشخیص داده می‌شود.
4. گزینه **Deploy** را انتخاب کنید.

پروژه برای اجرای اصلی به متغیر محیطی نیاز ندارد. نشانی نهایی Vercel نیز
به‌صورت خودکار در متادیتا، نقشه سایت و فایل راهنمای خزنده‌ها استفاده می‌شود.
اگر دامنه اختصاصی دارید، می‌توانید مقدار اختیاری `NEXT_PUBLIC_SITE_URL` را
برابر نشانی کامل همان دامنه قرار دهید.

## ساختار پروژه

منطق برنامه به‌صورت ماژولار جدا شده تا هرکدام مستقل قابل تست باشد:

```
lib/
  types.ts             تعریف نوع‌های مشترک دامنه
  nutrition/
    formulas.ts        محاسبات BMR/TDEE/کسری کالری/درشت‌مغذی‌ها + اعتبارسنجی مراحل
    format.ts          قالب‌بندی اعداد فارسی و گرد کردن
  food/
    catalogue.ts        فهرست وعده‌های غذایی و گزینه‌های فرم
  plan/
    build.ts            ساخت برنامه هفتگی قطعی (deterministic) + جایگزینی وعده
    shopping.ts          تجمیع فهرست خرید
components/
  SafetyAdvisory.tsx    یادداشت ایمنی/حریم‌خصوصی یک‌باره
app/
  DietPlanner.tsx        فقط رابط کاربری: وضعیت فرم، ناوبری مراحل، نمایش نتیجه
```

مستندات کامل تصمیم‌های محصولی و معماری در `CONTEXT.md`، `docs/research.md`،
`docs/architecture-assessment.md`، `docs/prototype-evaluation.md`، و
`docs/adr/` آمده است.

## تست

مجموعه تست با Vitest و Testing Library نوشته شده و رفتار عمومی (نه جزئیات
پیاده‌سازی) را می‌آزماید: فرمول‌های تغذیه‌ای، کسری کالری امن، فیلتر حساسیت/سبک
غذایی/غذاهای ناپسند، تعیّن (determinism) برنامه با seed یکسان، جایگزینی وعده،
تجمیع فهرست خرید، ناوبری و اعتبارسنجی مراحل فرم، دسترس‌پذیری، ناوبری با
صفحه‌کلید، عدم فراخوانی شبکه یا ذخیره‌سازی مرورگر، و خروجی متنی/چاپ.

```bash
npm run test
npm run test:coverage
```
